# Preventive Maintenance Schedule
Document status: SYNTHETIC (authored for this portfolio project). Operating limits mirror the rules used to generate the AI4I 2020 dataset.
Failure type: General

## Daily
Visual check of coolant level, cutting tool condition and unusual noise or vibration.

## Weekly
Inspect cooling fans and filters. Review tool_wear counters and plan tool changes before the counter reaches about 180-200 minutes.

## Quarterly
Calibrate torque and speed sensors. Inspect belts, couplings and drive components. Inspect bearing assemblies and lubricate. Check coolant system flow and top up.

## After Any Failure
Log the failure, the suspected cause and the corrective action in the maintenance records so future investigations can find similar incidents.
